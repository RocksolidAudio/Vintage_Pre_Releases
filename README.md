# Vintage Pre

Installers for Vintage Pre, a valve preamp from a 1950s mixing desk using realtime circuit simulation, from [Rocksolid Audio](https://rocksolidaudio.co.uk/).

## Download

The newest version is always here: [Latest release](https://github.com/RocksolidAudio/VintagePre_Releases/releases/latest)

- macOS: the `.dmg`
- Windows: the `.zip`

Close your DAW before running the installer.

## Free

Vintage Pre is free. Open it, sign in with a free Rocksolid Audio account, and it's yours, with its own serial number.

## Updates

Vintage Pre checks this page for new versions and tells you in its About screen when one is out. You can download it from inside the plugin, or just come back here whenever you like.

Every release below lists what changed.
